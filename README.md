# 🎯 PlacementOS — AI Placement Intelligence Monitor

> A self-hosted, AI-powered placement tracking system that automatically monitors your college placement Telegram group, extracts opportunities using Google Gemini, and presents them in a premium real-time dashboard.

---

## ✨ Features

| Feature | Description |
|---------|-------------|
| 🤖 **AI Extraction** | Gemini AI parses placement announcements from Telegram messages and PDFs |
| 🔴 **Live Monitoring** | Telethon userbot listens to your placement group 24/7 |
| 📊 **Smart Dashboard** | Priority-sorted opportunities with urgency tracking |
| 🧠 **CSE Intelligence** | Automatically scores and flags CSE-relevant opportunities |
| 📅 **Deadline Calendar** | Visual calendar showing all deadlines, assessments, and interviews |
| 🔔 **Auto Reminders** | Telegram notifications sent automatically before deadlines |
| 📈 **Analytics** | Weekly drive trends, top skills, apply rate, CSE/non-CSE split |
| 📥 **Historical Import** | Upload Telegram chat exports to analyze past opportunities |
| 🔒 **JWT Auth** | Secure login (username + password + 5-digit security code) |
| ⚙️ **Eligibility Profile** | Configure your branch, CGPA, and preferences for smart filtering |

## 🚀 Quick Start

### Prerequisites

- Python 3.11+
- Node.js 18+
- MongoDB (local or Atlas)
- Telegram account (for userbot)
- Google Gemini API key (optional; local extraction works without it)

### 1. Clone the repo

```bash
git clone <your-repo-url>
cd placement-tracker
```

### 2. Backend setup

```bash
cd backend

# Install dependencies
pip install -r requirements.txt

# Configure environment
cp .env.example .env   # Then edit .env with your values
```

### 3. Configure `.env`

```env
# Telegram Bot (from @BotFather)
TELEGRAM_BOT_TOKEN=your_bot_token
TELEGRAM_CHAT_ID=your_telegram_user_id

# Telethon Userbot (from https://my.telegram.org)
TELEGRAM_API_ID=your_api_id
TELEGRAM_API_HASH=your_api_hash
TELEGRAM_SESSION_STRING=    # Generated by setup_session.py
PLACEMENT_GROUP_ID=         # Your placement group/channel ID

# Optional Google Gemini enhancement. Local Python extraction is the default.
GEMINI_ENABLED=false
GEMINI_API_KEY=

# MongoDB
MONGODB_URI=mongodb://localhost:27017
MONGODB_DB=placement_monitor

# Admin Credentials (for dashboard login)
ADMIN_USERNAME=sunil
ADMIN_PASSWORD=Sunil@369
ADMIN_SECURITY_CODE=48411
JWT_SECRET=super-secret-key-369
```

### 4. Generate Telegram session

```bash
# Run once to authenticate your Telegram account
python setup_session.py
# Copy the printed TELEGRAM_SESSION_STRING into .env
```

### 5. Start backend

```bash
uvicorn main:app --reload
# API docs: http://localhost:8000/docs
```

### 6. Frontend setup

```bash
cd ../frontend
npm install
npm run dev
# Open: http://localhost:5173
```

## 🛠️ Configuration

All settings are managed via `backend/.env`. Key options:

| Variable | Default | Description |
|----------|---------|-------------|
| `CATCHUP_DAYS` | `10` | Days of history to scan on startup |
| `WATCHDOG_INTERVAL_MINUTES` | `30` | Userbot health check interval |
| `DAILY_SUMMARY_HOUR` | `8` | Hour (IST) for daily Telegram summary |
| `GEMINI_FLASH_MODEL` | `gemini-3.6-flash` | Fast extraction model |
| `GEMINI_PRO_MODEL` | `gemini-3.1-pro-preview` | High-confidence escalation model |
| `CONFIDENCE_THRESHOLD` | `0.70` | Below this → escalate to Pro model |
