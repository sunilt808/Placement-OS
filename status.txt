1. PROJECT PURPOSE
------------------------------------------------------------------------
Problem: The college placement cell floods a Telegram group with 100+
messages/day. Company drives, deadlines, eligibility rules and
registration links get buried -> students miss real opportunities.

Solution: A self-hosted AI pipeline that ingests placement messages from
Telegram (live userbot + manual forward-bot + historical export import),
extracts structured opportunities locally (NLP first, Gemini optional),
deduplicates them into a single evolving record per drive, tracks
deadlines deterministically in Python, sends Telegram reminders before
deadlines, and shows everything in a React "Placement Control Center".

Core design principle (docs/plan1.txt): recall > precision. A false
alert is acceptable; a missed genuine opportunity is not. AI understands
messages; Python owns state/deadlines/reminders.

Stack: FastAPI + Motor/MongoDB + Telethon + python-telegram-bot +
APScheduler + spaCy/dateparser + RapidFuzz + optional Google Gemini |
React 19 + Vite + Axios + react-hot-toast.

2. ARCHITECTURE (AS ACTUALLY BUILT — VERIFIED)
------------------------------------------------------------------------
INGESTION (3 paths, one shared pipeline):
  A. userbot.py        Telethon personal-account listener on the
                       placement group; PDF download+extraction;
                       startup catch-up scan (dynamic catchup_days read
                       from DB app_settings); manual scan trigger.
  B. telegram_bot.py   Bot API: manual forwards + full command set
                       (/start /help /jobs /today /urgent /deadlines
                       /applied /pending /expired /stats /search)
                       + inline callback buttons.
  C. telegram_importer.py  Historical JSON/TXT/HTML export parser,
                       keyword pre-filter, batch processing,
                       SSE progress streamed to /api/import/upload.

PIPELINE (services/message_pipeline.py):
  content-hash dedup -> store raw message -> classify_and_extract()
  -> process_extraction() -> Telegram alert. Failed extractions keep
  the raw row + processing_error for retry; duplicate placement
  messages without an opportunity get retried once.

AI LAYER (services/ai_service.py):
  Local NLP extractor (nlp_extractor.py, 755 lines: spaCy NER if
  installed, dateparser date anchoring to original message timestamp,
  company corpus + blacklist, regex field patterns) ALWAYS runs.
  Gemini Flash is an OPTIONAL enhancer; escalates to Pro below
  confidence_threshold=0.70; 429-aware retries; hallucination guards
  for company/role; merge prefers local for identity fields.
  Works fully offline with GEMINI_ENABLED=false.

STATE ENGINE (services/opportunity_engine.py):
  Dedup Layer 1 exact signature (company|role|normalized URL),
  Layer 2 RapidFuzz token_set_ratio >= 75 vs recent opps.
  Creates/updates opportunities, logs event timeline
  (opportunity_events), detects deadline extensions ->
  reschedules reminders, recomputes eligibility each update.

DEADLINES & REMINDERS:
  deadline_engine.py: EXPIRED/TODAY(<=3h)/WITHIN_24H/TOMORROW/
  WITHIN_3_DAYS/THIS_WEEK/UPCOMING/NO_DEADLINE, all UTC-computed,
  IST-displayed. reminder_service.py schedules 3-day/24h/3h alerts,
  cancels on APPLIED/IGNORED, reschedules on extension.
  scheduler.py jobs: reminder check every 15 min, daily summary at
  08:00 IST, watchdog every 30 min, message purge 03:15 IST
  (retention 3 days).

ELIGIBILITY (services/eligibility_service.py):
  Profile (branch/batch/CGPA/min CTC/locations/roles) stored in
  app_settings -> per-opportunity ELIGIBLE/NOT_ELIGIBLE/UNCLEAR +
  relevance_score 0-100 + itemized checks. Never hides opportunities.

API (all verified):
  POST /api/auth/login, GET /api/auth/me
  GET  /api/opportunities            (status/category/eligibility/
                                      search/days/cse_only/urgency)
  GET  /api/opportunities/stats | /meta/briefing | /meta/calendar
  GET  /api/opportunities/{id} | /{id}/timeline
  PATCH /api/opportunities/{id}/status   DELETE /{id}
  GET  /api/opportunities/messages          (raw inbox inspection)
  GET  .../messages/{id}/attachment         (retained source file)
  GET  /api/opportunities/{id}/source-document
  GET  /api/reminders
  GET/POST /api/settings/profile | /system_config
  POST /api/settings/scan_history    GET /api/settings/system
  POST /api/import/upload (SSE)      GET  /api/import/status
  GET  /api/health                   Docs at /docs

FRONTEND (React 19, dark glassmorphism):
  Login (credentials + 5-digit code) -> JWT in localStorage.
  Pages: Dashboard (greeting + briefing + stat cards + urgent lists),
  Opportunities (search/filter), OpportunityDetail (timeline +
  MatchScore + source doc), Applications, CalendarView, Messages
  inbox, Reminders, Import (drag-drop + SSE progress), Settings
  (profile + system config + scan trigger). Protected routes via
  useAuth; axios interceptor attaches Bearer token.

4. GAPS FOUND (VERIFIED, ORDERED BY SEVERITY)
------------------------------------------------------------------------
CRITICAL BUGS
G1. services/ai_service.py uses re.search in _validate_gemini_company
    (_validate_gemini_role) but NEVER imports re -> guaranteed
    NameError crash of the whole extraction whenever Gemini mode is
    enabled and returns a company/role candidate. Latent today only
    because GEMINI_ENABLED=false by default.

    the opportunities/import/reminders/settings routers depend on the
    token. Anyone who can reach port 8000 can read every message,

    Login page is theater, not security.
